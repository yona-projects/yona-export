# M5. 대용량 검증/벤치마크

## 목표
소규모~대용량(GB급 첨부, 수만 이슈/댓글) 합성 프로젝트로 전체 파이프라인 왕복을 검증하고 성능 목표를 확정한다.

## 범위
- 합성 데이터 생성 스크립트(이슈/댓글/첨부파일 규모 파라미터화)
- 1.6 extractor → 2.0 importer 전체 경로 벤치마크(메모리 사용량, 소요 시간, 재개 시나리오)
- 데이터 완전성 검증 자동화(원본 counts vs import 후 counts)
- 운영 인스턴스(1.6/2.0) 부하 영향 측정

## 의존성
M2, M3, M4

- [ ] 목표 성능 수치 확정 및 문서화(예: N GB / M만 건을 X시간 내)
- [ ] 완전성 리포트 0건 손실 확인
